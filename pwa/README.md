# اپ‌های گیت‌هاب هخامنش (لوگو + سوپابیس)

لینک گوگل (`script.google.com`) روی گوشی بدون لوگو ذخیره می‌شود. این پوشه همان شش اپ را از گیت‌هاب سرو می‌کند تا **Add to Home screen** لوگوی شرکت را بگذارد. خود اپ همان وب‌اپ ثابت Apps Script است؛ لایهٔ سریع سوپابیس داخل همان صفحه می‌ماند.

قبلاً همین کار ترکیبی فقط روی **سرویس‌کار** انجام شده بود (`serviceman-pwa/`).

## لینک نصب

ریپو خصوصی است؛ jsDelivr فایل‌ها را سرو نمی‌کند. برای اجرای روی گوشی با لوگو، GitHub Pages را روشن کنید:

Settings → Pages → Source: GitHub Actions

بعد از ادغام در `main` و یک‌بار اجرای workflow، ریشهٔ سایت همین پوشه است:

`https://mazrooee-viewer.github.io/hakhamanesh-apps/`

| اپ | مسیر |
|---|---|
| فهرست | `/` |
| مدیر قیمت | `/price-manager/` |
| بازاریاب قیمت | `/price-sales/` |
| مدیر فروش CRM | `/crm/` |
| مدیر فنی | `/board/` |
| سرویس‌کار | `/serviceman/` |
| داشبورد مرکزی | `/dashboard/` |

لینک قدیمی `serviceman-pwa/` همان الگوی سرویس‌کار است و بعد از Pages جداگانه سرو نمی‌شود؛ از `/serviceman/` استفاده کنید.

## سوپابیس

پنج اپ عملیاتی از قبل `FastLayer` دارند (تیکت، کارتابل سرویس، فرم بازدید، صندوق قیمت، برد فنی). پوستهٔ گیت‌هاب فقط iframe است؛ کلیدها همان Script Properties وب‌اپ‌اند:

- `FAST_SUPABASE_URL`
- `FAST_SUPABASE_ANON_KEY`

داشبورد مرکزی منبع شیت مشکلات است و هنوز FastLayer جدا ندارد.

## نصب روی گوشی

1. لینک گیت‌هاب را در کروم / سافاری باز کنید، نه لینک گوگل.
2. منو → Add to Home screen / نصب برنامه.
3. آیکون باید لوگوی هخامنش باشد.
